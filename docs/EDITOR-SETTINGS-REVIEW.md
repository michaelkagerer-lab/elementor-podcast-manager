# Episode editor and settings review

The dashboard polish had not carried through to daily editing: the episode screen opened with instructional prose instead of useful navigation, show settings were a long administrative table, optional configuration competed with primary actions, and analytics looked like disconnected form fragments.

The local revision keeps native WordPress publishing, media dialogs, Screen Options and Elementor behavior. It adds direct episode-section navigation with focus transfer and collapsed-panel recovery, an accessible audio preview with loading/error/retry states, and a bounded description editor after window resizing. Show settings use labeled field groups, visible section navigation, a clear primary save action and truthful unsaved-change feedback. Hosting, setup, distribution, design and analytics share the restrained neutral surfaces and spacing. Player previews retain the user's actual saved design.

The harsh follow-up review removed the mobile floating save bar, corrected primary-link contrast and the description field's accessible name, reduced nested mobile panels, repaired German labels and zoomed layout, and preserved the consequential hosting/migration and consent instructions. Native publishing and saved field names remain unchanged.

Evidence is in `../review/editor-settings/`: before, intermediate and responsive screenshots, browser interaction logs, accessibility results and security regressions. The local show uses seven imported public BUSINESS TUNING episodes; production-private settings are not available. This is local verification, not production acceptance.
