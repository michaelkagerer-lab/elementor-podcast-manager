# Findings register — 1.4.0 work

Baseline: `main` at `b1076c8` (plugin 1.3.0). Every finding below was reproduced on a
disposable WordPress 7.1.2 + Elementor 4.3.3 site (PHP 8.4, SQLite; MariaDB 10.11 and
nginx/Apache + php-fpm where the finding needed them) before any code changed. The
reproduction scripts and their raw output are the auditors' working files; each fixed
finding has a regression test in the repository that failed on the unfixed code.

Status values: **confirmed** (reproduced, not fixed), **fix implemented; regression tests not run in this environment** (code and regression coverage are present, but the test has not been executed on this checkout), **fixed and tested** (regression test failed before and passed after), **externally blocked** (needs a device, licence, account or service not available here), and **rejected** (does not hold, with the reason).

Priorities: P0 data loss, exploitable security issue or a core journey broken; P1 wrong
result in a main user path or likely data-integrity risk; P2 robustness or UX problem
with a workaround; P3 polish.

Totals: 2 × P0, 15 × P1, 41 × P2, 48 × P3 (106 findings).

## Limits of proof

Not proven by anything in this register: real iOS/Safari and Android devices (WebKit
automation is not iOS Safari), screen readers, Elementor Pro (Theme Builder, Loop
Carousel, Popups), real external embedding on third-party sites, production CDN and
host behavior (the test router fakes HEAD/Range), and a full MySQL/MariaDB load profile.
Directory requirements were checked against the official pages that could be fetched
on 2026-10-01; Amazon and Podcast Index pages could not be fetched.

## Follow-up: resumed media integrity

The handoff's missing `If-Range` validation is fixed. A real-socket test
failed before the change: a replaced enclosure produced a mixed file while
reporting success. Resumed requests now validate strong ETags or modification
dates and restart when the file changes. Unverifiable partial copies fail
safely and retain the original address. The full media runner passes 65
assertions plus the 60 MB memory case; the 15 targeted assertions also pass
on WordPress 6.2. Full-disk tmpfs cases were skipped because this local runner
is not root.

## Final handoff improvements

Import steps read only the current GUID and bounded database chunks. An abandoned
media-copy lock now becomes recoverable after five minutes, as other imports do;
active workers renew it between items. Media copying requires PHP cURL so stalled
